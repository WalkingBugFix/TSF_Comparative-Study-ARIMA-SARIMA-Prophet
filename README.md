# TSF_Comparative-Study-ARIMA-SARIMA-Prophet
This project aims to forecast monthly gas consumption using three time series forecasting models—ARIMA, SARIMA, and Facebook Prophet—and compare their predictive performance.

**Project Description:**
This project aims to forecast monthly gas consumption using three time series forecasting models—ARIMA, SARIMA, and Facebook Prophet—and compare their predictive performance. The dataset comprises historical gas consumption data, which was log-transformed and differenced to ensure stationarity where required. Each model was tuned and evaluated based on Root Mean Squared Error (RMSE) on a held-out test set. While ARIMA and SARIMA demonstrated reasonable performance, Prophet achieved the lowest RMSE, highlighting its strength in capturing seasonality and trend without extensive manual preprocessing. The study concludes with insights into model selection for time series forecasting tasks in energy consumption domains.
